# Key and Dealer Plate Accountability Checklist
**Used by:** Lot Manager; anyone handling Key Cafe transactions
**Applies to:** Any sign-out or sign-in of a key or dealer plate; periodic audits
**Key Cafe location:** 3rd floor by Jorja's desk

---

## Instructions

Complete the applicable section of this checklist for every key and dealer plate transaction. Every item is answered Yes or No only. Every No triggers the specified Failure Action immediately — do not release any item until all sign-out checks pass.

**Financial penalties (all enforced — not theoretical):**
- Dealer plate lost: **$500** — charged to the employee who last signed it out through Key Cafe
- GPS key tag lost: **$25** — charged to the employee who lost it
- Vehicle keys lost: **~50% of replacement cost** — charged to the employee who lost them
- Confirmed precedent: an employee at this dealership paid the full $500 dealer plate penalty. It was not forgiven.

---

## SECTION A — SIGN-OUT CHECKS
*Complete before issuing any key or dealer plate.*

[ ] **1. Is the employee's signed Accountability Agreement on file?**
    YES: Continue
    NO — Failure Action: ROLE: Lot Manager → STOP. Do not issue the key or plate. SAY: "I can't issue keys or plates until you've signed the accountability agreement. See [Sales Manager/General Manager] to complete that before returning." Do not make exceptions. No access without a signed agreement on file.

[ ] **2. Is this sign-out being conducted through Key Cafe (not a peer-to-peer handoff)?**
    YES: Continue
    NO — Failure Action: ROLE: Lot Manager → redirect the employee to Key Cafe (3rd floor by Jorja's desk). If someone is attempting to hand you a key or plate to pass along to them, SAY: "You need to check it out through Key Cafe yourself — I can't accept it from you." Direct them to Key Cafe immediately.

[ ] **3. Is the transaction being logged with the employee's name and timestamp before the item is released?**
    YES: Continue
    NO — Failure Action: ROLE: Lot Manager → log the transaction (employee name + timestamp) before releasing the item; do not release the item until it is logged in Key Cafe

[ ] **4. Is the requested item currently available — specifically, is it not currently signed out to another employee?**
    YES: Continue
    NO — Failure Action: ROLE: Requesting employee → do not request the item from the employee who currently has it peer-to-peer; either (a) wait for the item to be returned through Key Cafe, OR (b) contact the employee who currently has it and ask them to return it through Key Cafe first; then sign it out through Key Cafe yourself

---

## SECTION B — SIGN-IN CHECKS
*Complete before accepting any returned key or dealer plate.*

[ ] **5. Is the item being returned directly to Key Cafe by the employee who signed it out — specifically, is it NOT being handed to a coworker to return on their behalf?**
    YES: Continue
    NO — Failure Action: ROLE: Lot Manager → redirect the employee. SAY: "You need to return it through Key Cafe yourself — you're responsible for it until you check it in there." Direct them to Key Cafe (3rd floor by Jorja's desk) immediately.

[ ] **6. Is the return transaction being logged with the employee's name and timestamp before the item is marked as available?**
    YES: Continue
    NO — Failure Action: ROLE: Lot Manager → log the return transaction (employee name + timestamp) before marking the item as available; do not mark the item available until the return is logged in Key Cafe

---

## SECTION C — PERIODIC AUDIT CHECKS
*Run at the start of each day OR when any item cannot be located.*

[ ] **7. Does the Key Cafe log account for all items that should currently be signed out — specifically, can every currently-signed-out item be matched to a log entry with an employee name and sign-out timestamp?**
    YES: Continue
    NO — Failure Action: ROLE: Lot Manager → reconcile the log; identify any transactions that are not logged; document the discrepancy in WhatsApp team chat; if any item cannot be accounted for after reconciliation, escalate to General Manager immediately

[ ] **8. Are all GPS key tags physically attached to their key sets?**
    YES: Continue
    NO — Failure Action: ROLE: Lot Manager → check the GPS location of the missing tag before declaring it lost; if located via GPS: retrieve the tag and reattach it to the correct key set; if the tag cannot be located after GPS check: initiate → SEE: key-plate-lost-response.md; $25 reprogram cost applies and is charged to the employee responsible

## Failure Action Summary

| Item | Failure Role | Failure Path |
|---|---|---|
| 1 — No accountability agreement on file | Lot Manager | STOP. No access. Direct employee to sign agreement with Sales Manager or General Manager first. |
| 2 — Not using Key Cafe | Lot Manager | Redirect to Key Cafe. Refuse peer-to-peer transaction. |
| 3 — Not logged before release | Lot Manager | Log transaction before releasing item. |
| 4 — Item not available | Requesting employee | Wait for return through Key Cafe or request current holder return through Key Cafe first. |
| 5 — Not returning to Key Cafe in person | Lot Manager | Redirect employee. They must return it themselves. |
| 6 — Return not logged | Lot Manager | Log return before marking available. |
| 7 — Log does not account for all items | Lot Manager | Reconcile; document discrepancy in WhatsApp; escalate to General Manager if unresolved. |
| 8 — GPS key tag not attached | Lot Manager | Check GPS location; reattach if found; initiate lost response if not found; $25 penalty applies. |

## The Peer-to-Peer Transfer Rule — Absolute

**Never accept a key or dealer plate directly from a coworker.**
**Never hand a key or dealer plate directly to a coworker.**

If a coworker asks for the plate or key you currently have signed out, say exactly:

> **"No — go back to Key Cafe, I'll check mine in, you sign it out."**

This is the exact language. There is no alternative acceptable response.

**Why:** If you hand a plate to a coworker without going through Key Cafe, Key Cafe still shows you as responsible. If that plate is lost, you pay the $500 penalty — even though you no longer have it. The custody chain exists to protect you.
